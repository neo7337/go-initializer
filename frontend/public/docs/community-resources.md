# Community Resources

A curated list of Go resources to help you level up after generating your project.

## Official

- [go.dev](https://go.dev) — Official Go website, documentation, and playground
- [Go Blog](https://go.dev/blog) — In-depth articles from the Go team
- [pkg.go.dev](https://pkg.go.dev) — Package documentation for the entire Go ecosystem

## Learning

| Resource | Description |
|----------|-------------|
| [A Tour of Go](https://go.dev/tour/) | Interactive intro to Go syntax and concepts |
| [Go by Example](https://gobyexample.com) | Annotated example programs covering the standard library |
| [Effective Go](https://go.dev/doc/effective_go) | Official style guide and idioms |
| [100 Go Mistakes](https://100go.co) | Common pitfalls and how to avoid them |

## Open-source projects to study

- **[Caddy](https://github.com/caddyserver/caddy)** — Production-grade HTTP server; excellent example of plugin architecture
- **[Hugo](https://github.com/gohugoio/hugo)** — Static site generator; great example of CLI with Cobra
- **[Prometheus](https://github.com/prometheus/prometheus)** — Monitoring system; showcases large-scale Go service design

## Community

- **[Gophers Slack](https://gophers.slack.com)** — The main Go community chat (invite at [invite.slack.golangbridge.org](https://invite.slack.golangbridge.org))
- **[r/golang](https://reddit.com/r/golang)** — Reddit community for Go news and questions
- **[Go Forum](https://forum.golangbridge.org)** — Q&A forum for Go developers

## Newsletters & Podcasts

- **[Golang Weekly](https://golangweekly.com)** — Weekly digest of Go articles
- **[Go Time](https://changelog.com/gotime)** — Podcast covering Go in production, tooling, and community
